The aim of this project is to implement an autonomous maze-navigation algorithm on a mBot platform. Utilizing an ultrasonic sensor, an IR sensor and an LDR with red, green and blue LEDs to form a color sensor circuit, the mBot has to drive through the maze maintaining a minimum clearance from the walls, detecting waypoint markers in the form of colored papers on the ground and executing the corresponding turns. The robot reads each colored paper to decide its next move, such as turning left, turning right, turning around, double left, double right or stopping at the end of the maze.
